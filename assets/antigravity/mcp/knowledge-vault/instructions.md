# Knowledge Vault MCP Instructions

Knowledge Vault lưu trữ toàn bộ tài liệu kỹ thuật, kiến trúc dự án, best practices, quy chuẩn coding (Sitecore, multi-site, impact matrix, guidelines).

## Hướng dẫn sử dụng Tools:
1. `context_for_query`:
   - **Ưu tiên sử dụng đầu tiên** khi người dùng hỏi các câu hỏi kỹ thuật, quy tắc, hướng dẫn hoặc nghiệp vụ. Tool này tự động tổng hợp các chunk liên quan nhất thành định dạng Markdown có sẵn nguồn trích dẫn.
2. `hybrid_search`:
   - Dùng khi cần lấy danh sách chunk chi tiết kèm điểm xếp hạng RRF (Reciprocal Rank Fusion) BM25 + Vector.
3. `read_note`:
   - Dùng khi đã biết đường dẫn file ghi chú cụ thể và cần đọc toàn bộ nội dung file.
